# alx-project-nexus — getSocial (Social Media Backend)

> **Type:** Project Nexus documentation (guide-style, build-log)  
> **Author:** garisonmike (@garisonmike)

This repository documents the process of building **getSocial**, a social-media backend using **Django 5.x**, **Django REST Framework**, **GraphQL (Graphene-Django)**, and **PostgreSQL**. Everything here is written as a *guide while building*, not “after the project”. We’ll keep updating as we progress.
